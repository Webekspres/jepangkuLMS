# Panduan Pengguna — JepangKu LMS

Buku panduan operasional untuk **siswa**, **sensei/admin**, dan staf yang mengelola konten di `kursus.jepangku.com`.

Dokumen ini ditulis untuk orang yang **bukan developer** — fokus langkah demi langkah di antarmuka web.

> **Versi PDF (disarankan untuk dibagikan):** [JepangKu-LMS-Panduan-Lengkap.pdf](./JepangKu-LMS-Panduan-Lengkap.pdf) — gabungan semua bab di bawah.  
> Regenerasi: `bun run guide:pdf`
